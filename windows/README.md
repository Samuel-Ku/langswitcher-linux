# LangSwitcher для Windows 11

Порт [LangSwitcher for macOS](https://github.com/Samuel-Ku/langSwitcher) під Windows:
той самий алгоритм (фізичні позиції клавіш, автовизначення), дефолт `en,uk,pl`.
Скрипт і файл даних, без Python — тільки AutoHotkey v2.

## Встановлення (один рядок у PowerShell)

```powershell
irm https://raw.githubusercontent.com/Samuel-Ku/langswitcher-linux/main/windows/install.ps1 | iex
```

Або вручну: постав [AutoHotkey v2](https://www.autohotkey.com/), поклади
`LangSwitcher.ahk` **і `langswitcher-data.txt`** в `%APPDATA%\LangSwitcher\` і
запусти (або двокліком `install.bat` з цієї папки — зробить усе сам: winget,
копія, автозапуск, завантаження даних).

`langswitcher-data.txt` — не в репозиторії: він похідний від CC BY-SA 4.0
корпусу, а цей проєкт під MIT. Обидва інсталятори качають його з release-ассета,
**звіряють SHA-256** і лише потім підміняють встановлене. Без мережі:

```powershell
# розпакуй langswitcher-data-<версія>.tar.gz із релізу і вкажи теку:
$env:LANGSWITCHER_DATA_DIR = "C:\path\to\unpacked"; .\install.ps1
```

Без файлу даних авторежим **сам вимикається** (у треї видно, що даних немає) і
не вгадує.

Тримай файл `LangSwitcher.ahk` у кодуванні **UTF-8** (там кириличні таблиці).

## Використання

| Дія | Як на macOS |
|---|---|
| Виділив `ghbdsn` → подвійний Shift | `привіт` (як `⇧⇧`) |
| Друкуєш `ghbdsn` + пробіл | слово саме міняється на `привіт` (як Punto Switcher) |

- Подвійний Shift спрацьовує тільки на «чистих» натисканнях Shift
  (з великими літерами `AB` конфлікту немає — див. `A_PriorKey`).
- Рішення авторежиму — те саме, що на Linux/Omarchy (три рівні): слово власної
  мови не чіпаємо (`hello`, `the`, `привіт`), відоме слово цілі перетворюємо
  (`z` → `я`, `wt` → `це`, `еру` → `the`), а решту вирішує оцінка літерних
  n-грамів — тож перетворюються і відмінкові форми (`абетки`), і одруки, і
  український IT-сленг. Саме тому потрібен файл даних: раніше тут була
  евристика «нема голосної», яка лишала половину звичайних слів як є.
- Авторежим вимикається в меню іконки в треї (там же ручна конвертація).
- **Layout Switch mode (як у macOS):** після конвертації міняється й системна
  мова вводу на цільову (`LoadKeyboardLayout` + `WM_INPUTLANGCHANGEREQUEST`),
  щоб наступне слово вже було правильним. Тумблер — у треї
  («Switch layout after convert»).
- Налаштування (`auto on/off`) зберігається в `settings.ini` поруч зі скриптом.

## Розкладки

- Реальна конвертація: `en↔uk` з автовизначенням.
- Польська programisty фізично = US QWERTY; текст з діакритикою
  (`ą ć ę ł ń ó ś ź ż`) **ніколи не чіпається** — ні хоткеєм, ні автозаміною.
- **Польська через ⌥-шар (як у macOS):** якщо набрати польський текст, коли
  активна кирилична розкладка, діакритичні ⌥-акорди виходять символами цієї
  розкладки (`ą`=⌥+A→`ƒ`, `ś`=⌥+S→`ы`, `ć`=⌥+C→`≠`, `ż`=⌥+Z→`ђ`). Подвійний
  Shift відновлює їх за фізпозицією: `ьƒлф` → `mąka`, `сяуы≠` → `cześć`.

## Обмеження (чесно)

- Автозаміна працює зі звичайними текстовими полями; у полях паролів і
  деяких іграх вимкни скрипт через трей (пауза) — натискання все одно
  доходять, але зайва магія там ні до чого.
- `Ctrl+Backspace` посеред слова може збити буфер поточного слова
  (наступний пробіл/Enter усе синхронізує).
- Рішення звіряється з Python-ядром у CI: job `windows-parity` прогонить
  `linux/tests/parity-corpus.txt` через `LangSwitcher.ahk --dump` і через ядро
  й падає на першій же розбіжності. Тобто цей файл перевіряється живим
  запуском на Windows-раннері, а не лише читанням коду.

## Файли

- `LangSwitcher.ahk` — хуки, таблиці розкладок, рішення, трей
- `langswitcher-data.txt` — списки слів і n-грами (качається інсталятором, у git його немає)
- `install.bat` — встановлення двокліком (з папки репозиторію)
- `install.ps1` — встановлення одним рядком (з GitHub)
